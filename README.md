# MICIR — micro infrarouge pour violoncelle

Quatre couples émetteur infrarouge (SFH 4646) / phototransistor (SFH 3605), un par corde, sur un circuit collé au chevalet. La corde coupe le faisceau en vibrant ; le courant du phototransistor est le signal.

- `kicad/` : schéma et circuit (KiCad 5, projet `MICIR_cello3`), empreintes dans `MICIR_cello.pretty`, exports SVG des deux faces.
- `datasheet/` : fiche technique de l'émetteur.
- `essais-2020.wav` : premier essai sonore, octobre 2020.

Fiche du projet : https://electro-crea.com/projets/micir/
